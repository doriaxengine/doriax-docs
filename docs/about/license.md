# License &amp; Credits

## License

Doriax Engine is released under the **MIT License** and is free for both personal and
commercial use — no royalties, no strings attached.

Third-party libraries bundled in the repository keep their own respective licenses.

## Credits

Doriax Engine is created and maintained by **Eduardo Doria**. It is the continuation of
**Supernova Engine** under a new identity, extending the original ECS, data-oriented
runtime with a full editor and export pipeline.

### Built with

Doriax integrates several open-source libraries, including:

| Library | Use |
| --- | --- |
| [Box2D](https://box2d.org/) | 2D physics |
| [Jolt Physics](https://github.com/jrouwe/JoltPhysics) | 3D physics |
| [Lua](https://www.lua.org/) | Scripting |
